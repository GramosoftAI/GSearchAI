# ADR 3: Evidence-First Retrieval

## Status
Accepted

## Context
When answering questions over structured graphs, the LLM needs context. Simply passing a summary of relationships is insufficient for enterprise audits, where every claim must be traceable.

## Decision
Every inferred relationship must have at least one piece of `Evidence` attached (e.g., `foreign_key_heuristic` linking `user_id` to `id`). During retrieval, the `Response Assembler` forces the context injected into the LLM prompt to include this evidence block. 

## Consequences
- **Positive:** Every answer generated by the platform can be fully audited back to the original `(sheet, table, row, cell)`.
- **Negative:** Graph storage size is increased to hold the evidence and provenance metadata.
